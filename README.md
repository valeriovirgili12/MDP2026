# 🪐​ Cowboy BebOOP

RPG narrativo a scelte multiple ambientato in un futuro distopico ispirato a *Cowboy Bebop*.  
Il giocatore veste i panni del capitano della **Blue Mantis**, una nave da bounty hunting coinvolta in una cospirazione galattica. Tre episodi, otto finali, nessuna scelta innocua.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25
- Gradle

### Istruzioni
Aprire powershell come amministratore e far partire i seguenti comandi uno dopo l'altro
```bash
winget install EclipseAdoptium.Temurin.25.JDK

java -version

git clone https://github.com/valeriovirgili12/it.unicam.mpgc.rpg126421.git

cd it.unicam.mpgc.rpg126421
```
```bash
Windows (PowerShell):
.\gradlew.bat build
```
```bash
Windows (PowerShell):
.\gradlew.bat run
```
